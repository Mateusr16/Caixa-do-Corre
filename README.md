# Caixa do Corre

App Android para anotar ganhos e gastos de entregas e mandar o resumo pelo WhatsApp.

## Baixar no celular
1. Abra a aba **Releases** deste repositório, no celular.
2. Baixe o arquivo **CaixaDoCorre.apk**.
3. Abra o arquivo e permita "instalar apps desconhecidos" quando o Android pedir.

O APK é gerado automaticamente pelo GitHub (aba Actions) a cada alteração na pasta `www`.
Os dados ficam guardados no próprio celular.
